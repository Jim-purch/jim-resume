## 什么是 OH 卡？为什么需要 AI 镜像？

**OH Cards（潜意识投射图像卡）** 是心理学中非常经典且有效的投射沟通工具。卡牌没有标准答案，每一幅画面都是一面镜子，使用者在画面中看到什么，往往映射了其当下内心的焦虑、渴望或尚未被言说的情感。

然而在传统的咨询中，OH 卡通常需要专业引导师在旁把控节奏，这给许多希望进行日常自我觉察、梳理情绪但又注重私密性的普通人带来了门槛。

**[OH-MindMirror](https://github.com/Jim-purch/oh-mindmirror)** 的目标，就是利用大模型的多模态能力与精心编排的引导性提示工程，充当一个**中立、包容、不带评判的“数字倾听者与镜像引导师”**。

## 核心设计难点与工程实践

### 1. 规避“好为人师”：拒绝廉价的说教与鸡汤

许多 AI 心理类产品最常犯的错误，就是过早地下定义或给出空泛的“行动指南”：“你现在感到疲惫，建议多喝水、早点睡觉……”。这种机械的应答会直接打断用户的内心感受流。

在 **OH-MindMirror** 中，我们设计了严格的 **二阶投射交互链（Two-Step Projection Chain）**：

- **阶段一：现象描述（Phenomenological Seeing）**
  引导用户只描述画面中的客观要素：“画面中有哪些物体？线条和色彩给你什么直观感觉？”
  通过去意向化的观察，先让大脑从防御状态松弛下来。
- **阶段二：隐喻连接（Metaphorical Bridging）**
  模型不直接给出解释，而是提出开放式问题：“如果画面中的这个小角落代表你现实生活中的某件事，你第一直觉会想到什么？”
  通过隐喻启发用户自行完成意义构建。

### 2. 视觉多模态多维感知架构

我们选用了 **Google Gemini 2.0 Flash / Pro** 的视觉理解接口：

```typescript
// 核心提示词与角色约束逻辑示意
const SYSTEM_PROMPT = `
你是一位温和、克制、富有同理心的 OH 卡探索陪伴者。
核心准则：
1. 严禁对用户进行心理学病理化标签归类或居高临下的道德评判。
2. 严禁主动断定画面的象征意义（例如："红色的花代表你的爱情"），只能将其作为问题抛回给用户。
3. 你的职责是提问，引导对方说出更多他们自己的故事。
4. 语言风格：留白、质朴、倾听。
`
```

通过传入当前抽取的卡牌高分辨率图像与用户的文字描述，Gemini 能够极其细腻地捕捉用户描述与卡面细节之间的张力（例如卡面原本是阳光明媚的森林，但用户却把焦点放在了阴影中的石块上），并据此给出精准的回应提问。

## 隐私优先与端侧架构

心理探索的内容具有极高的隐私敏感度：

- **无数据库日志沉淀**：用户的每一次探索会话纯保存在浏览器的 LocalStorage / IndexedDB 中。
- **直连 API Key 模式**：用户可自行配置个人 Google AI API Key，数据直接由浏览器向官方端点发起安全请求，不经过任何第三方中间服务器。
- **一键导出脱敏卡片**：支持将会话核心觉察生成一张审美雅致的“探索心语卡片”（基于 HTML-to-Image），方便用户存入个人的 Notion 或笔记软件中。

## 部署与体验

项目采用极简的纯静态单页架构（Vite + React + Tailwind CSS），你可以直接部署在 Vercel、Cloudflare Pages 或任何静态服务器：

```bash
# 克隆仓库
git clone https://github.com/Jim-purch/oh-mindmirror.git
cd oh-mindmirror

# 安装依赖并启动
npm install
npm run dev
```

构建你的个人镜像：[GitHub 仓库地址](https://github.com/Jim-purch/oh-mindmirror)。
