## 痛点：macOS 系统音频内录的传统困局

在 macOS 上参加线上会议、观看外语技术分享或收听播客时，如果想把电脑正在播放的声音实时转成文字，通常会遇到三个门槛：

1. **权限与采集受限**：普通麦克风接口无法直接录制其他应用程序播放的系统声音；
2. **虚拟声卡配置繁琐**：安装 BlackHole / Soundflower 并配置多输出设备不仅上手成本高，系统升级后还容易出现无声或声道错乱；
3. **云端转写的隐私顾虑**：将内部会议或敏感内容上传至第三方云端语音 API 存在合规与泄露风险。

**[Mac Voice to Text](https://github.com/Jim-purch/mac-voice-to-text)** 基于 **Tauri v2 + Rust + Swift 原生插件** 构建，不装任何虚拟声卡，完全在 macOS 本地端侧完成系统音频采集与实时文字转写。

## 跨语言分层架构

项目采用三层架构兼顾原生性能与现代桌面 UI 开发效率：

```text
React 19 + TypeScript 前端界面 (Vite)
        │  Tauri invoke / 状态轮询
        ▼
Tauri v2 Rust 后端 (src-tauri/src/lib.rs, audio_bridge.rs, storage.rs)
        │  C ABI FFI (@_cdecl, 链接静态库 libAudioCapture.a)
        ▼
Swift 原生模块 (swift-plugin/Sources/AudioCapture/)
  ├─ AudioCaptureManager.swift  ── Apple ScreenCaptureKit 系统内录
  └─ SpeechRecognizer.swift     ── Apple SFSpeechRecognizer 端侧识别
```

## 核心技术实现

### 1. 免虚拟声卡的系统内录（`AudioCaptureManager.swift`）

自 macOS 13 (Ventura) 起，苹果提供的 `ScreenCaptureKit` 支持直接拦截系统输出音频。我们在 Swift 插件中以最小视频开销（2×2 像素、1 FPS）启动纯音频捕获流，并直接输出 16kHz 单声道 Float32 PCM 采样：

```swift
let filter = SCContentFilter(display: display, excludingApplications: [], exceptingWindows: [])
let config = SCStreamConfiguration()
config.capturesAudio = true
config.excludesCurrentProcessAudio = true // 避免本应用自身声音回环
config.sampleRate = 16000
config.channelCount = 1

let stream = SCStream(filter: filter, configuration: config, delegate: self)
try stream.addStreamOutput(self, type: .audio, sampleHandlerQueue: audioQueue)
try await stream.startCapture()
```

整个链路纯用户态运行，仅需用户授予标准的「屏幕录制」与「语音识别」系统权限即可工作。

### 2. 端侧实时语音识别（`SpeechRecognizer.swift`）

捕获到的音频采样通过 `@_cdecl` 导出的 C 回调函数经 Rust `audio_bridge.rs` 转发至 `SFSpeechAudioBufferRecognitionRequest`，由 Apple 原生 `SFSpeechRecognizer` 进行实时转写：

- **端侧优先**：优先使用设备端离线识别（`supportsOnDeviceRecognition`），音频数据不离开本机；
- **多语言切换**：内置简体中文、繁体中文、英语（美/英）、日语、韩语、西/法/德语等常见语言选项；
- **增量缓冲管理**：Rust 层区分 `is_final = false` 的实时中间句（`CURRENT_TRANSCRIPTION`）与 `is_final = true` 的已确认段落（`CONFIRMED_BUFFER`），保证前端字幕平滑刷新不抖动。

### 3. 本地历史归档与多格式导出

- 每次停止转录后，Rust 后端的 `StorageManager`（`storage.rs`）会自动将完整文本、语言与时长保存为本地 JSON 记录；
- 支持历史记录检索、删除以及一键导出为 **TXT / Markdown / JSON** 文件。

## 安装与本地构建

### 直接下载安装包

前往 [GitHub Releases](https://github.com/Jim-purch/mac-voice-to-text/releases) 下载 Apple Silicon 版本 `.dmg`（当前已发布 `v0.1.0`）。

### 从源码编译（macOS 13.0+）

```bash
git clone https://github.com/Jim-purch/mac-voice-to-text.git
cd mac-voice-to-text

# 1. 编译 Swift 原生静态库
cd swift-plugin && swift build -c release && cd ..

# 2. 安装前端依赖并启动 Tauri 开发模式
npm install
npm run tauri:dev

# 构建发布包
npm run tauri:build
```
