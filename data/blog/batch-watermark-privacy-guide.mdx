## 敏感证照与商图的隐私痛点

日常办公中，无论是提交身份证/营业执照复印件加注“仅供某某业务使用”，还是给大量商品图批量盖上品牌防盗水印，把图片上传到陌生第三方在线工具都存在泄露与速度瓶颈。

**[纯前端批量水印工具（put-watermark-web）](https://github.com/Jim-purch/put-watermark-web)** 坚持一个核心原则：**所有图片与文档处理 100% 在用户本地浏览器内完成，零文件上传服务器**。

## 核心功能与技术实现

### 1. HTML5 Canvas 全分辨率本地渲染（`src/App.jsx`）

为了避免预览图压缩导致的输出糊图，核心渲染流程始终以原图真实像素尺寸（`image.naturalWidth × image.naturalHeight`）创建离屏 Canvas 进行绘制：

- **双水印模式**：同时支持**文本水印**（自定义文案、字体、字号、字重、颜色、阴影、透明度、旋转角）与**图片 Logo 水印**（支持本地上传或预设 PNG、自由缩放比例）；
- **灵活布局**：支持九宫格锚点定位（左上、居中、右下等）以及可调横向/纵向间距的倾斜平铺矩阵，防止边缘裁切；
- **实时预览与无损保留**：基于首张选中图片实时刷新效果；导出时透明 PNG 自动保留 Alpha 通道，JPEG 以 92% 高画质输出。

```javascript
// 全分辨率 Canvas 平铺水印绘制逻辑示意
function drawTextWatermark(ctx, opts) {
  const { width, height } = ctx.canvas
  const rad = (opts.angle * Math.PI) / 180
  const stepX = Math.max(opts.spacingX, opts.fontSize * 2)
  const stepY = Math.max(opts.spacingY, opts.fontSize * 2)

  for (let y = -stepY; y < height + stepY; y += stepY) {
    for (let x = -stepX; x < width + stepX; x += stepX) {
      ctx.save()
      ctx.translate(x, y)
      ctx.rotate(rad)
      ctx.fillText(opts.text, 0, 0)
      ctx.restore()
    }
  }
}
```

### 2. 前端 `JSZip` 批量打包与扩展工具箱

处理多张图片后，应用直接在浏览器内存中通过 `JSZip` 打包为单个 `.zip` 文件供一键下载，无需逐张点击保存。

随着日常高频需求沉淀，项目还在同一个纯前端导航框架内扩展了多个本地免上传实用模块：

- **PDF 转换工具（`PdfConverter.jsx`）**：基于 `pdfjs-dist` 在本地解析与裁剪导出 PDF 页面图片；
- **文件提取与链接校验（`FileExtractor.jsx`）**：本地快速批量提取和校验文件链接；
- **图片转 ICO 图标（`ImageConverter.jsx`）**：本地生成多尺寸浏览器 Favicon `.ico`。

## Docker 多阶段构建与私有化部署

仓库内置多阶段 `Dockerfile`（Node 阶段执行 `vite build`，运行阶段仅用 `nginx:alpine` 托管静态产物）及 `docker-compose.yml`，适合企业内网一键自托管：

```bash
git clone https://github.com/Jim-purch/put-watermark-web.git
cd put-watermark-web

# 方式一：Docker Compose 一键启动（默认映射至 docker-compose.yml 配置端口）
docker compose up -d --build

# 方式二：手动构建并运行
docker build -t put-watermark-web:latest .
docker run -d --name put-watermark-web -p 8080:80 --restart unless-stopped put-watermark-web:latest
```

容器运行期不依赖 Node.js，仅由 Nginx 托管纯静态文件，内存占用极低，可在完全断网的局域网环境中稳定运行。
