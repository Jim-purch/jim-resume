## 为什么要做云表格跨表检索平台？

在中小企业与汽配/外贸团队日常协作中，业务数据往往分散在十几份不同的 WPS 云表格与 Google Sheets 中：报价表、库存表、供应商对照表各自独立。传统方式下，销售或采购需要频繁切换十几个表格逐一 `Ctrl+F`，而直接把表格原链接和脚本令牌发给员工，又存在权限失控与泄露风险。

**[云表格快速查找平台（websearch-wps-webhook）](https://github.com/Jim-purch/websearch-wps-webhook)** 正是为此设计的全栈中台：在不改变团队继续用云表格维护数据的前提下，提供**令牌托管、权限分享、跨表多条件批量检索、结果导出与 MCP 配置生成**的一站式工作台。

---

## 全栈技术栈选型

- **前端与全栈框架**：Next.js 16（App Router + Turbopack）+ React 19 + TypeScript
- **数据库与鉴权**：Supabase（PostgreSQL + Auth + RLS 行级安全）
- **样式与交互**：Tailwind CSS v4 + 深浅主题切换（`ThemeContext`）
- **结果导出**：`exceljs` + `file-saver`（保留件号文本格式，避免长数字变科学计数法）
- **部署运维**：Vercel + `vercel.json` 定时 Keep-Alive Cron（`/api/cron/keep-alive`）

## 关键工程实践

### 1. Supabase 行级安全（RLS）与 Token 分享权限模型

平台管理的核心资产是用户的 WPS AirScript Webhook 令牌与 Google Sheets 配置。为了杜绝越权访问，所有核心表（`user_profiles`、Token 表、分享表、搜索预设表、审计日志表）均在 PostgreSQL 层开启 RLS 策略：

- 用户只能读写自己名下的 Token 与搜索预设；
- 通过**分享码（`/shares/[code]`）**分发数据时，可精细控制权限级别为 `view`（仅查看）或 `use`（可使用检索但不暴露底层敏感凭据），并支持设置过期时间；
- 新注册账户默认受管理后台激活控制（`/inactive` 拦截），管理后台（`/admin`）支持用户角色（`user` / `admin`）、登录日志与 Token 使用频次统计。

### 2. 服务端代理与跨源云表格统一抽象

WPS AirScript Webhook 存在浏览器 CORS 限制，且表格内的 `DISPIMG` 图片链接带有防盗链与有效期约束。我们在 `src/app/api/` 与 `src/lib/` 中构建了统一代理与适配层：

- **`/api/wps/proxy` & `/api/image-proxy`**：由 Next.js Route Handler 代为转发 Webhook 查询与图片拉取，解决前端跨域并隐藏部分上游细节；
- **双源适配器（`src/lib/wps/` & `src/lib/googlesheets/`）**：把 WPS 智能表格、WPS 多维表格与 Google Sheets 统一抽象成一致的表列表与检索接口，并对 Google Sheets 查询引入内存 TTL 缓存（`GOOGLE_SHEETS_CACHE_TTL_SECONDS`）。

### 3. 批量件号搜索的分批回退与结果增量累积

业务人员经常一次粘贴几百个件号进行跨表批量查价，单次大包请求极易触发 WPS AirScript 执行超时。在 `usePartSearch` 与 `src/lib/wps/queue.ts` 中，我们做了以下工程容错：

1. **自动分批回退（Chunked Fallback）**：批量请求超时或超限时，按可配置的 `NEXT_PUBLIC_WPS_FALLBACK_CHUNK_SIZE`（默认 `10`）自动拆片重试；
2. **增量展示与占位对齐**：结果表格（`ResultTable.tsx`）实时累积已返回的批次结果，同时对未命中的件号保留占位行，方便直接核对缺失项；
3. **搜索预设与 Excel 导出**：支持将常用的多表组合与列隐藏配置保存为 Preset，一键复用并将结果按文本单元格格式导出为 `.xlsx`。

### 4. 一键打通 AI Agent（MCP 配置生成）

工作台内置了 `MCPConfigDrawer` 组件：勾选任意多个云表格 Token 后，系统会自动拼装出兼容 **[jim-wps-mcp-server](https://github.com/Jim-purch/jim-wps-mcp-server)** 的 `WPS_CONFIG` JSON，复制到 Claude Desktop 或 Cursor 即可让 AI 直接检索同一批业务表。
